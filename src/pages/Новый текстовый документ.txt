"MusicGame" is an open‑source web game that helps beginners learn to recognise musical notes by ear. It combines a virtual piano, a hidden note on a staff, and a cute fox mascot that gives visual feedback. The game is built with React, TypeScript, and the Web Audio API, and it runs entirely in the browser – no installation or special hardware required.
Although the project is relatively new, it already has a small but growing user base among music teachers and self‑taught students. It fills a gap in free, accessible ear‑training tools that are both engaging and pedagogically sound. The code is well‑structured and serves as a learning resource for junior developers interested in interactive audio applications.
I am actively adding new features (levels, hints, more games) and plan to promote it in music education communities. With wider adoption, it could become a go‑to tool for schools and individual learners worldwide.
